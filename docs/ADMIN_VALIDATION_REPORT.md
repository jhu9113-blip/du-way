## 2. 통합 사용자 흐름

### 관리자 진입

- 일반 사용자 라우트는 인증 없이 접근한다.
- `/admin` 하위 화면은 인증되지 않은 경우 `/admin/login`으로 전환한다.
- 관리자 계정은 `admin / admin` 하나만 사용한다.
- 빈 로그인 입력과 잘못된 계정은 각각 한국어 오류 문구를 표시한다.
- 로그아웃하거나 새로고침하면 관리자 인증이 초기화된다.

### 데이터 편집과 사용자 미리보기

- 건물명·좌표·진입 안내 변경은 관리자 지도와 사용자 홈·길안내에 반영된다.
- 시설명·유형·좌표·안내 변경은 공유 지도에 반영된다.
- 경로 지표·경고·노드 변경은 관리자 미리보기와 사용자 길안내에 반영된다.
- 수업과 홈 고정 안내값 변경은 사용자 홈과 시간표에 반영된다.
- 개별 데이터 초기화와 전체 초기화 경로가 제공된다.

### 예외 상태

- GPS 실패 상태는 사용자 길안내에 대체 출발지 안내를 표시한다.
- 경로 없음 상태는 사용자 길안내에 설정 이동이 가능한 대체 화면을 표시한다.
- 관리자 데모 화면과 사용자 설정 화면은 동일한 예외 상태를 변경한다.
- 데모 초기화와 대시보드 전체 초기화는 두 예외 상태를 정상으로 복구한다.

## 3. 접근성 및 반응형 감사

### 확인 및 보완 항목

- 공용 토글 전체를 하나의 `role="switch"` 버튼으로 구성해 중첩 인터랙티브 요소를 제거했다.
- 관리자 경로 선택은 `role="group"`과 `aria-pressed` 버튼으로 표현해 불완전한 탭 패턴을 제거했다.
- 로그인 오류를 두 입력의 `aria-describedby`와 연결하고 `aria-invalid`를 제공한다.
- 폼 필드는 명시적인 `label`과 `id` 연결을 사용한다.
- 오류는 `role="alert"`, 적용 완료 메시지는 `role="status"`로 전달한다.
- 버튼·링크·입력은 44px 이상의 조작 높이와 `focus-visible` 스타일을 사용한다.
- 관리자 메뉴는 모바일에서 가로 스크롤 메뉴, 데스크톱에서 고정 폭 세로 메뉴로 전환한다.
- 편집 화면은 작은 폭에서 단일 열, 넓은 폭에서 다중 열로 전환한다.
- 로그인 화면의 1280px headless 렌더링에서 중앙 정렬과 내용 잘림이 없음을 확인했다.

현재 Windows의 Chrome·Edge headless CLI는 작은 창 폭을 내부 최소 폭으로 보정하므로 375px 캡처 결과는 최종 판정에 사용하지 않았다. 실제 브라우저 개발자 도구의 375px device viewport에서 가로 스크롤과 포커스 이동을 한 차례 확인하는 것을 발표 전 수동 체크리스트로 유지한다.

## 4. 정적 검증 명령

```powershell
.\node_modules\.bin\eslint.cmd .
.\node_modules\.bin\tsc.cmd --noEmit --incremental false
.\node_modules\.bin\next.cmd build
```

금지 항목 검색 대상:

- `fetch`, `axios`
- `localStorage`, `sessionStorage`
- 카카오·네이버·구글 지도 SDK
- 회원가입, 비밀번호 찾기, 다중 관리자와 권한 설정 UI
- 이름·학번·이메일·장애 유형 입력 필드

## 5. 발표 전 수동 체크리스트

- [ ] 실제 브라우저 375px viewport에서 관리자 로그인과 각 편집 화면에 불필요한 가로 스크롤이 없다.
- [ ] 1280px에서 사이드바와 편집 영역이 겹치지 않는다.
- [ ] Tab과 Shift+Tab으로 모든 관리자 조작 요소에 접근한다.
- [ ] Enter·Space로 버튼과 토글을 조작한다.
- [ ] 잘못된 폼 입력 후 오류 문구와 포커스 위치를 확인한다.
- [ ] `admin / admin` 로그인, 로그아웃, 새로고침 초기화를 확인한다.
- [ ] 건물·시설·경로·데모 값을 각각 수정하고 사용자 화면 반영을 확인한다.
- [ ] GPS 실패와 경로 없음 상태를 켰다가 초기화한다.
- [ ] 브라우저 콘솔에 오류가 없는지 확인한다.

## 6. 알려진 제약

- `admin / admin`은 클라이언트에 노출되는 시연용 진입 장치이며 실제 보안 인증이 아니다.
- 새로고침하면 관리자 로그인과 모든 편집값이 초기화된다.
- 관리자에서 수정한 데이터는 다른 브라우저나 사용자와 공유되지 않는다.
- 사용자 홈 미리보기는 사용자 앱의 온보딩 상태에 따라 `/onboarding`으로 이동할 수 있다.
- 실제 서비스 전환 시 서버 인증, 데이터베이스, 권한 검증과 감사 로그를 새로 설계해야 한다.
