# DU WAY 발표 시연 가이드

## 시연 전 준비

1. 브라우저 폭을 모바일 기준인 375px 안팎으로 맞춘다.
2. `/onboarding`에 접속한 상태에서 페이지를 새로고침한다.
3. 온보딩 첫 화면과 모든 선택값이 초기 상태인지 확인한다.
4. 발표 중 사용할 이동 조건을 미리 정한다. 권장 시나리오는 `수동 휠체어`, `계단 피하기`, `완만한 경사 우선`이다.

DU WAY는 PRD에 따라 상태를 저장하지 않는다. 전체 페이지를 새로고침하면 Context 상태가 초기화되므로 `/onboarding`에서 다시 시작할 수 있다.

## 정상 흐름

1. 온보딩에서 이동 수단과 경로 선호 조건을 선택한다.
2. `시작하기`를 눌러 홈으로 이동한다.
3. 홈에서 다음 내용을 설명한다.
   - 다음 수업: UX 디자인, 10:30, 경상대학 1402호
   - 출발지: 성산홀
   - 추천 출발: 10:14
   - 예상 이동: 13분
   - 연강으로 3분 부족
4. `오늘 시간표 보기`를 눌러 월요일 수업 2개와 다음 수업 표시를 확인한다.
5. `여기로 길안내`를 눌러 길안내 화면으로 이동한다.
6. 기본 무장애 경로에서 760m, 11분, 계단 0곳과 엘리베이터·경사로 안내를 확인한다.
7. `빠른 경로` 탭으로 전환해 620m, 8분, 계단 1곳과 급경사 경고를 비교한다.
8. 하단 `설정` 탭으로 이동해 이동 조건과 도착 여유 시간을 변경한다.

## GPS 실패 시나리오

1. 설정의 `시연용 상황 재현`에서 `GPS 실패 상황`을 켠다.
2. 하단 `길안내` 탭으로 이동한다.
3. 현재 위치를 확인할 수 없다는 안내와 성산홀 기준 대체 안내를 설명한다.
4. `GPS 실패 상황 해제하기`를 눌러 설정으로 돌아간다.
5. 토글을 끄고 길안내 화면에서 정상 상태로 복구됐는지 확인한다.

## 경로 없음 시나리오

1. 설정에서 `경로 없음 상황`을 켠다.
2. 길안내 화면으로 이동한다.
3. 조건에 맞는 경로가 없다는 설명과 설정 이동 버튼을 확인한다.
4. `설정에서 조건 조정하기`를 눌러 설정으로 돌아간다.
5. 토글을 끄고 길안내 화면에서 정상 경로가 다시 표시되는지 확인한다.

## 문제 발생 시 복구

- 상태가 예상과 다르면 `/onboarding`으로 이동한 뒤 전체 페이지를 새로고침한다.
- 화면이 넓게 보이면 브라우저 개발자 도구에서 375px 폭으로 변경한다.
- 경로 화면이 비어 있으면 설정에서 `경로 없음 상황`이 꺼져 있는지 확인한다.
- GPS 경고가 남아 있으면 설정에서 `GPS 실패 상황`을 끈다.
- 발표 데이터와 실제 캠퍼스 정보가 다르다는 질문에는 현재 좌표와 경로가 현장조사 전 시연용 목업임을 설명한다.

## 최종 체크리스트

- [ ] 온보딩에서 개인정보를 묻지 않는다.
- [ ] 하단 탭에 아이콘과 한국어 텍스트가 함께 표시된다.
- [ ] 추천 출발 10:14, 예상 이동 13분, 3분 부족이 정확하다.
- [ ] 무장애 경로는 실선, 빠른 경로는 파선이다.
- [ ] 위험 상태에 아이콘과 설명 문구가 함께 표시된다.
- [ ] GPS 실패와 경로 없음 상태에서 설정으로 돌아갈 수 있다.
- [ ] 마우스 없이 Tab, Shift+Tab, Enter, Space 및 경로 탭 방향키를 사용할 수 있다.
